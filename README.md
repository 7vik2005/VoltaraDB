# Go-based distributed key-value database

## Development Workflow

To contribute to VoltaraDB, create a separate branch for your changes and keep commits focused on a single improvement.

```bash
git checkout -b your-branch-name
git add .
git commit -m "describe your change"
git push -u origin your-branch-name
```

Before submitting changes, make sure the project builds successfully and that existing tests pass.
